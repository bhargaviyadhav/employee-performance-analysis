# 👩‍💼 Employee Data Analysis

## 📊 Project Overview
This project focuses on analyzing employee data to understand employee performance, salary distribution, department-wise employees, and other important business insights.

## 🎯 Objectives
- Analyze employee information.
- Identify department-wise employee distribution.
- Analyze salary distribution.
- Understand employee performance.
- Create meaningful visualizations and dashboards.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Excel
- SQL
- Power BI
- Google Colab

## 📁 Dataset Details
The dataset contains **200 employee records** with details such as:
- Employee ID
- Employee Name
- Age
- Gender
- Department
- Job Role
- Salary
- City
- Experience
- Performance Rating

## 🧹 Data Cleaning
The following data cleaning steps were performed using Python and Pandas:
- Checked for missing values.
- Removed duplicate records.
- Corrected data types.
- Verified the cleaned data.
- Checked for duplicate rows.
- Prepared the dataset for analysis.

## 🗄️ SQL Analysis
SQL was used to analyze employee data and answer business questions.

Queries included:
- Total number of employees.
- Average salary of employees.
- Department-wise employee count.
- Highest and lowest salary.
- Employees with more experience.
- Salary analysis by department.

## 📈 Power BI Dashboard
The dashboard includes:
- Total Employees
- Average Salary
- Department-wise Employee Count
- Salary by Department
- Employee Performance
- Employee Distribution by City

## 💡 Key Insights
- Identified departments with the highest number of employees.
- Analyzed average salary across departments.
- Compared employee performance ratings.
- Identified salary distribution across different job roles.
- Analyzed employee experience.
